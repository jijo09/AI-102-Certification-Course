💡 Reporting Key Traps

Line reports REQUIRE a real Date/DateTime field — a text "year" field won't work. DB Views are read-only with no Business Rules. PA vs Reports distinction: Reports = point-in-time snapshot; PA = historical time-series that needs to be collecting data over time. Interactive Filters only affect widgets on the SAME dashboard using the SAME source table.
