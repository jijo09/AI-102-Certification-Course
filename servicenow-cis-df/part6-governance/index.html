💡 The #1 Trap in Part 6

Exam constantly confuses Data Policy vs UI Policy. UI Policy = client-side JavaScript = only affects the form = bypassable via REST API. Data Policy = server-side = enforces on form AND REST API AND import sets = truly server-enforced. Know this cold. Also: Dictionary Override only works on INHERITED fields, never on fields defined directly on that same table.
