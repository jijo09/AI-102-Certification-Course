Discovery scans IP ranges and applications, MID Servers bridge network boundaries, Discovery Patterns determine what to collect, Service Mapping builds application dependency maps, and Agent/ACC extends coverage to isolated devices. 💡 Discovery Exam Focus Areas

Key traps: MID Server is required for Discovery on private networks (not public cloud APIs), IP Range Discovery finds new CIs while CI Group Discovery refreshes known CIs, Discovery Patterns populate CI attributes using Probes and Sensors, and Service Mapping builds the CSDM Application Service model. Know when each tool is appropriate and what its limitations are.
